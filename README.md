# Bella Bistro

A modern and responsive restaurant website built using HTML, CSS, and JavaScript.

## Live Demo

https://laya107.github.io/bella-bistro/

## Features

- Modern restaurant website design
- Responsive layout for desktop and mobile
- Smooth navigation
- Restaurant menu section
- Interactive menu cards
- Table reservation form
- Reservation confirmation message
- Contact section
- Hover effects
- Mobile-friendly design

## Technologies Used

- JavaScript
- Git

- GitHub Pages
